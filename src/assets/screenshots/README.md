# Screenshots

Drop real Cherry Creek screenshots here and the site uses them on the next
build, replacing the illustrated placeholders:

| File                          | Used for                  | Suggested size      |
| ----------------------------- | ------------------------- | ------------------- |
| `hero.jpg` (or png/webp/avif) | Home page hero background | 2560×1440 or larger |
| `map.jpg` (or png/webp/avif)  | "Explore the world" card  | 1600×1000 or larger |

They are resized and converted automatically. Update the alt text for each in
`src/config/site.ts`. Only use screenshots taken on Cherry Creek.
